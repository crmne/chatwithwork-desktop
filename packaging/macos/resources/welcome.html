Chat with Work Local Agent lets Chat with Work read, and with your approval change files and run commands, in folders you share on this Mac, and nothing else.

  • Folders are read-only unless you allow changes, and run no commands unless you allow those too, with each change and run approved by you.
  • Only the folders you share, and never the secrets inside them.
  • Outbound only: no port is opened on your Mac.

This installs Chat with Work in Applications, the cww terminal interface in /usr/local/bin, and a per-user background agent that stays idle until you pair this Mac.
