## New

- **Print PDFs from a chat.** Turn a printer on in **Settings, Printers**, or with `cww printers`, and a chat can print a PDF from its files there, on Linux and Mac through CUPS and on Windows through the print spooler. You approve every job in Chat with Work, and it shows the file, pages, copies and printer. By @crmne ([#110](https://github.com/crmne/chatwithwork-desktop/pull/110)).
- **Lend a printer to a bot.** A bot's **Share this computer** can lend it a printer and, separately, let it print there unattended. Both are decided on the computer. This computer prints at most 200 pages a day, copies counted, and you can change that with `print_pages_per_day`. By @crmne ([#110](https://github.com/crmne/chatwithwork-desktop/pull/110)).

## Fixed

- **Chats no longer stop with "the hourly read budget is used up".** Reads, tool calls, copies and changes have no time-based limit by default. Size limits per call, file and message still apply, and so do each command's CPU, memory and run time. You can still set any of these limits under `[limits]`; a saved value that equals an old default now counts as unset, so choose another number to keep a cap. By @crmne ([#109](https://github.com/crmne/chatwithwork-desktop/pull/109)).
- **The `zip` library is updated to 9.2.0 for five security advisories.** They include [CVE-2026-115905](https://nvd.nist.gov/vuln/detail/CVE-2026-115905). Desktop reads Office files in memory and doesn't extract archives to disk. By @crmne ([#107](https://github.com/crmne/chatwithwork-desktop/pull/107)).
- **Commands can't get another command's answer.** When a request to the supervising process was abandoned partway, its late answer could reach the next request. By @crmne ([#110](https://github.com/crmne/chatwithwork-desktop/pull/110)).
- **Windows starts the bundled browser engine.** By @crmne ([#108](https://github.com/crmne/chatwithwork-desktop/pull/108)).

## Known limitations

- **Printing needs a current Chat with Work server.** Update self-hosted servers too.
- **Printing hasn't been tried on a physical printer.** It was tested through CUPS on Linux and macOS and through Windows' spooler to Microsoft Print to PDF. Printers that open a save dialog aren't listed, and a network printer has to be set up on the computer first.
- **A print that stops partway isn't retried.** If the system stops answering and the job may have printed, its pages stay counted and the same job won't print again, so you never get it twice. Check the printer, then send it again as a new job.
- **Hourly limits no longer protect against a runaway chat by default.** [SECURITY.md](https://github.com/crmne/chatwithwork-desktop/blob/main/SECURITY.md) says what they stopped; set them under `[limits]` if you want them back.
- **Word writing still uses `zip` 8.** `docx-rs` hasn't moved to `zip` 9. It only builds documents in memory ([details](https://github.com/crmne/chatwithwork-desktop/blob/main/docs/zip-review.md)).
- **Uninstalling on Windows can leave `cww.exe` behind.** Our installer test still catches this. If the file is there after an uninstall, you can delete its folder by hand.
- **Linux animations can still remain at 60 fps.**
- **The browser extension is still installed manually.**
- **Linux updates use the package manager or one-line installer.** On Mac, use the signed and notarized DMG; the PKG remains unsigned. Windows SmartScreen may warn while the installer builds reputation.
