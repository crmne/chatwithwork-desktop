Signing in to a second Chat with Work server no longer signs this computer out of the first, and when a computer does have to sign in again, one **Reconnect** does it. `chatwithwork://` links now open in the app, and you can manage bots from a terminal with `cww bots`.

## New

- **Links open in the app.** A `chatwithwork://` link goes to that page in the Chat with Work window, but only on the server this computer is paired with. Anything else is dropped. By @crmne ([#116](https://github.com/crmne/chatwithwork-desktop/pull/116)).
- **Manage bots from a terminal.** `cww bots` lists, creates, changes, pauses, runs and deletes them, for a person or an agent, with `--json`. A computer needs permission first: `cww login --bots`, or allow it in Settings on first use. By @crmne ([#114](https://github.com/crmne/chatwithwork-desktop/pull/114)).

## Fixed

- **Each server keeps its own sign-in.** Signing in to a second server, or signing out of one, could replace the first server's credentials, so a computer that had been working lost its connection later. Credentials are now kept per server, on Mac, Windows and Linux, and existing sign-ins carry over. By @crmne ([#117](https://github.com/crmne/chatwithwork-desktop/pull/117)).
- **Reconnect in one click.** The tray, Settings and Account now offer **Reconnect** when this computer has to sign in again, in plain words. A computer you removed from Chat with Work stays removed unless you approve it again. By @crmne ([#118](https://github.com/crmne/chatwithwork-desktop/pull/118)).
- **Switches respond at once.** A switch that takes a moment to save moves straight away and shows a spinner, and goes back if the change doesn't arrive. By @crmne ([#118](https://github.com/crmne/chatwithwork-desktop/pull/118)).
- **Windows uninstalls from a custom folder.** The program and its background agent no longer stay behind. A copy already installed there is fixed by updating to this version. By @crmne ([#120](https://github.com/crmne/chatwithwork-desktop/pull/120)).
- **Dependency updates.** `zip` 9.2.1, a security update, plus `pulldown-cmark`, fastframe and the browser engine. By @crmne ([#115](https://github.com/crmne/chatwithwork-desktop/pull/115)).

## Known limitations

- **Reconnecting takes a person's approval.** It signs in the usual way; it doesn't yet happen on its own.
- **The clearer "removed" message needs a current Chat with Work server.** On an older server, a removed computer reads as needing to sign in again.
- **Printing hasn't been tried on a physical printer.**
- **Linux animations can still remain at 60 fps.**
- **The browser extension is still installed manually.**
- **Linux updates use the package manager or one-line installer.** On Mac, use the signed and notarized DMG; the PKG remains unsigned. Windows SmartScreen may warn while the installer builds reputation.
