Chat with Work on a Mac now needs macOS 13.5 or later: macOS 11 and 12 are no longer supported. The browser engine runs on Node 26, which Node supports until April 2029.

Already installed? 0.12.0 or later on a Mac with macOS 13.5 or later, on Windows or as an AppImage installs this version by itself the next time it starts. Otherwise upgrade through the package manager you used (`brew upgrade`, `apt`, `dnf`, `zypper`, `pacman`). GitHub shows each file's SHA-256 beside it, and the signed `checksums.txt` lists all but the `.deb`, `.rpm` and Flatpak packages; [PACKAGING.md](https://github.com/crmne/chatwithwork-desktop/blob/main/PACKAGING.md#release-assets) says what each one is for.

## Changed

- **macOS 13.5 or later is required: macOS 11 and 12 are no longer supported.** Desktop carries its own copy of Node for the browser engine, and this release moves it from Node 22 to Node 26.12.1, which runs on macOS 13.5 or later only ([Node's supported platforms](https://github.com/nodejs/node/blob/v26.12.1/BUILDING.md#supported-platforms)). The app, the `.pkg`, the disk image and Homebrew now refuse older versions of macOS. On macOS 11 or 12, keep 0.13.1, the last version that runs there, or update macOS first. Windows and Linux need nothing new. By @crmne ([#105](https://github.com/crmne/chatwithwork-desktop/pull/105)).

## Known limitations

- **A Mac on macOS 11 or 12 may still be offered this update.** The updater checks that a new version starts before it switches to it, so the app stays on 0.13.1, but it can keep offering the update.
- **Folder environments are set from a terminal.** The app doesn't have a field for them yet.
- **The AppImage and Flatpak bundle can't start the background agent at login yet.** In the Flatpak, run the agent yourself with `flatpak run --command=cww com.chatwithwork.desktop daemon run` ([#138](https://github.com/crmne/chatwithwork-desktop/issues/138)).
- **The Flatpak bundle doesn't update itself.** No Flatpak repository publishes it yet, so Desktop shows the command that installs the new bundle.
- **Printing hasn't been tried on a physical printer.**
- **Linux animations can still remain at 60 fps.**
- **The browser extension is still installed manually.**
- **On Mac, use the signed and notarized DMG; the PKG remains unsigned.** Windows SmartScreen may warn while the installer builds reputation.
