## Fixed

- **On Linux, animations no longer flicker or jump in Chat with Work Desktop's window** (a WebKitGTK 2.54 drawing bug). WebKitGTK 2.54's new compositor showed the first frame of a fade or a slide again as it ended, so a hovered icon blinked and the sidebar dropped out for a frame as it settled. The app now draws with WebKitGTK's earlier compositor, still on the graphics card, at the same frame rate; `WEBKIT_USE_SKIA_FOR_COMPOSITION=1` turns the new one back on. By @crmne; thanks @crmne for reporting it ([#257](https://github.com/crmne/chatwithwork-desktop/pull/257)).
- **On Linux, the tray shows Chat with Work's name instead of cww-app.** Panels name a tray item by its title, which was the program's file name. By @crmne; thanks @crmne for reporting it ([#257](https://github.com/crmne/chatwithwork-desktop/pull/257)).
