## Fixed

- **On Linux, animations no longer flicker or jump in Chat with Work Desktop's window, and the top bar shows at once** (a WebKitGTK 2.54 drawing bug). WebKitGTK 2.54's new compositor showed the first frame of a fade or a slide again as it ended, so a hovered icon blinked and the sidebar dropped out for a frame as it settled. The app now draws with WebKitGTK's earlier compositor, still on the graphics card, at the same frame rate; `WEBKIT_USE_SKIA_FOR_COMPOSITION=1` turns the new one back on. By @crmne; thanks @crmne for reporting it ([#257](https://github.com/crmne/chatwithwork-desktop/pull/257)).
- **On Linux, the tray shows Chat with Work's name instead of cww-app.** Panels name a tray item by its title, which was the program's file name. By @crmne; thanks @crmne for reporting it ([#257](https://github.com/crmne/chatwithwork-desktop/pull/257)).

![A white box fading in and out, frame by frame: with WebKitGTK 2.54's new compositor (0.18.0) frames jump back to the fade's start and the sidebar drops out for a frame; with this release's compositor the fade is smooth and nothing drops; from a test with synthetic data](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.18.1/linux-flicker.png)

- **Installing on Windows takes about a third less time.** The browser engine bundled with the app carried about 2,300 files nothing reads (type declarations, source maps, Markdown), and Windows checks every file an installer writes. They're left out now, keeping every licence and notice, so the engine has 2,457 files instead of 4,726. On a clean Windows 11 test machine the x64 installer took 67 s instead of 105 s, and uninstalling 106 s instead of 177 s. By @crmne ([#256](https://github.com/crmne/chatwithwork-desktop/pull/256)).
- **Dependency update.** `zip` 9.7.2. Renovate flagged it for [GHSA-m665-v7pm-7grj](https://github.com/zip-rs/zip2/security/advisories/GHSA-m665-v7pm-7grj), the advisory 0.17.0 and 0.18.0 already listed: Desktop has had the fix since before 0.13.0 ([docs/zip-review.md](https://github.com/crmne/chatwithwork-desktop/blob/main/docs/zip-review.md)), so it doesn't change what Desktop does. By Renovate and @crmne ([#254](https://github.com/crmne/chatwithwork-desktop/pull/254)).
