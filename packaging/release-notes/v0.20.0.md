Every download is now called Chat with Work Desktop, with the computer it's for in its name: `Chat-with-Work-Desktop-0.20.0-macOS-universal.dmg`, `Chat-with-Work-Desktop-0.20.0-Windows-x64.msi`, `Chat-with-Work-Desktop-0.20.0-Linux-x86_64.AppImage`. Each download people pick also has a link that always gives the newest version. Copies you already have keep updating: this release also carries the files under the names they look for.

## New

- **Downloads named for people.** Every file starts with `Chat-with-Work-Desktop`, then the version, then the computer: `macOS-universal`, `Windows-x64`, `Windows-arm64`, `Linux-x86_64`, `Linux-aarch64`. Before, the same app came as `chat-with-work-…`, `cww-…`, `cww-app-…` and `chatwithwork-desktop…`, with Rust's target names (`x86_64-pc-windows-msvc`) where you'd look for "Windows". The archives say what they are too: `Chat-with-Work-Desktop-0.20.0-Linux-x86_64-terminal-only.tar.gz` is the one with only `cww`. The one-line installers are `Chat-with-Work-Desktop-install.sh` and `Chat-with-Work-Desktop-install.ps1`. Package names don't change: `chatwithwork-desktop` on Linux, `chat-with-work` and `cww` in Homebrew. By @crmne ([#271](https://github.com/crmne/chatwithwork-desktop/pull/271)).
- **Links that always download the newest version.** The Mac disk image, both Windows installers, and the AppImage, `.deb` and `.rpm` for both processors also come without the version in their name, so [https://github.com/crmne/chatwithwork-desktop/releases/latest/download/Chat-with-Work-Desktop-macOS-universal.dmg](https://github.com/crmne/chatwithwork-desktop/releases/latest/download/Chat-with-Work-Desktop-macOS-universal.dmg) (and `Chat-with-Work-Desktop-Windows-x64.msi`, `Chat-with-Work-Desktop-Linux-x86_64.AppImage` and the rest) always gives the latest release. The README's first table lists them. By @crmne ([#271](https://github.com/crmne/chatwithwork-desktop/pull/271)).
- **The app's updater looks for the new names first,** and the old ones after. Its update notices link the new files. By @crmne ([#271](https://github.com/crmne/chatwithwork-desktop/pull/271), [crmne/fastframe#82](https://github.com/crmne/fastframe/pull/82)).
- **The signed `checksums.txt` lists every download,** the `.deb`, `.rpm`, Flatpak bundles and `.zsync` files included, which were only on GitHub's page before. By @crmne ([#271](https://github.com/crmne/chatwithwork-desktop/pull/271)).
- **Screenshots in the release notes aren't downloads any more.** They live with the notes, so this page lists only files to install. By @crmne ([#271](https://github.com/crmne/chatwithwork-desktop/pull/271)).

## Known limitations

- **For now, the files installed copies look for are also here under their old names** (`chat-with-work-v0.20.0-macos-universal.dmg`, `cww-v0.20.0-x86_64-pc-windows-msvc.msi`, `chatwithwork-desktop-0.20.0-x86_64.AppImage`, `cww-installer.sh` and the rest), because copies of 0.19.0 and older look for those names to update. The macOS archive and the two terminal-only archives come only under their new names: nothing installed looks for them. They go in a release no earlier than 21 January 2027. A copy still on 0.19.0 or older after that says "Couldn't verify version" in **General** instead of updating; download the new version by hand then.
- **After Chat with Work restarts, a computer can now and then say it's connected while chats see it offline,** until its background agent restarts ([#246](https://github.com/crmne/chatwithwork-desktop/issues/246)).
- **Another extension's popup over a field can leave a tab unreadable** ([#237](https://github.com/crmne/chatwithwork-desktop/issues/237)).
- **`cww roots` changes don't go through the daemon's ordered edit yet,** so a stalled change from the app can still undo one made in a terminal ([#239](https://github.com/crmne/chatwithwork-desktop/issues/239)).
- **On Windows, a pause pressed while a thinking step gets ready can miss it** ([#240](https://github.com/crmne/chatwithwork-desktop/issues/240)).
- **A folder that was missing when Desktop started stays "Folder not found" after it appears** until the background agent restarts ([#241](https://github.com/crmne/chatwithwork-desktop/issues/241)).
