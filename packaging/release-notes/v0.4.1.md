Chat with Work Desktop now carries its name everywhere: the Linux packages are `chatwithwork-desktop`, Windows installs to a "Chat with Work Desktop" folder, and the macOS app is `com.chatwithwork.desktop`.

**Download:** [macOS app](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.4.1/chat-with-work-v0.4.1-macos-universal.dmg), [Windows installer](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.4.1/cww-v0.4.1-x86_64-pc-windows-msvc.msi), [Debian/Ubuntu package](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.4.1/chatwithwork-desktop_0.4.1_amd64.deb), or [Fedora package](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.4.1/chatwithwork-desktop-0.4.1-1.x86_64.rpm). Arm builds and portable archives are in the release assets. On Arch, `yay -S chatwithwork-desktop-bin`; on macOS, `brew upgrade --cask chat-with-work`.

## New

- **New package names.** Arch: `chatwithwork-desktop-bin`, `chatwithwork-desktop` (built from source) and `chatwithwork-desktop-git`. Debian, Ubuntu and Fedora: `chatwithwork-desktop`. The `cww` command and the `cww-app` program keep their names. By @crmne ([#24](https://github.com/crmne/chatwithwork-desktop/pull/24)).
- **Windows installs to `%LOCALAPPDATA%\Programs\Chat with Work Desktop`**, and its background agent's logon task, Startup shortcut and start at login are named Chat with Work Desktop too. By @crmne ([#24](https://github.com/crmne/chatwithwork-desktop/pull/24)).
- **The macOS app's identifier is `com.chatwithwork.desktop`.** By @crmne ([#24](https://github.com/crmne/chatwithwork-desktop/pull/24)).

## Known limitations

- **Nothing carries over from 0.4.0's names.** Sign in to the Chat with Work window again. On Linux, remove `chatwithwork-local-agent` (or `-bin`, `-git`) before installing the new package; on Arch, pacman offers to. On macOS the app asks again for notifications and the microphone, and "Start at login" needs turning on again in Settings. On Windows the installer replaces 0.4.0; turn "Start at login" on again if you used it. Your pairing, shared folders and the agent's settings are kept everywhere.
- **Windows builds and the macOS `.pkg` remain unsigned.** The macOS `.dmg` is signed and notarized. Windows may show a SmartScreen warning.
- **On macOS and Windows, a connection lost while a page is open shows the web view's own error** until you reopen the window; only Linux switches to the offline page then.
- **On Windows on Arm, `cww tui` dictates only in the cloud.**
- **Linux needs WebKitGTK 4.1 and glibc 2.39 or newer** for the desktop package; the terminal-only `cww` archives still work elsewhere.
- **The app does not update itself.** Upgrade through your package manager or download this release. After upgrading a Linux package, run `systemctl --user restart cww.service`.
