Chat with Work Desktop scans paper: put pages in a USB scanner and get a searchable PDF, made on your computer, to save or send to Chat with Work. The app also carries its new name everywhere, from the packages to the Windows folder.

**Download:** [macOS app](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.5.0/chat-with-work-v0.5.0-macos-universal.dmg), [Windows installer](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.5.0/cww-v0.5.0-x86_64-pc-windows-msvc.msi), [Debian/Ubuntu package](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.5.0/chatwithwork-desktop_0.5.0_amd64.deb), or [Fedora package](https://github.com/crmne/chatwithwork-desktop/releases/download/v0.5.0/chatwithwork-desktop-0.5.0-1.x86_64.rpm). Arm builds and portable archives are in the release assets. On Arch, `yay -S chatwithwork-desktop-bin`; on macOS, `brew upgrade --cask chat-with-work`.

## New

- **Scan paper into searchable PDFs.** Choose Scan… in the tray (or run `cww-app --scan`), pick a scanner, color mode and resolution, and scan both sides. Blank backs are left out (you can bring them back), and you can reorder, turn, crop and delete pages before you finish. The text is read on your computer in the language you choose (Tesseract on Linux, Vision on macOS, Windows' own OCR on Windows) and laid over each page so you can search and select it; nothing is read on Chat with Work's servers. Linux and macOS scan through SANE, and Windows through the scanner's TWAIN driver. By @crmne ([#19](https://github.com/crmne/chatwithwork-desktop/pull/19)).
- **Save the PDF, or send it to Chat with Work.** Send starts a new chat with the PDF or hands it to a bot that takes scans. Save works without an account. By @crmne ([#19](https://github.com/crmne/chatwithwork-desktop/pull/19)).
- **New package names.** Arch: `chatwithwork-desktop-bin`, `chatwithwork-desktop` (built from source) and `chatwithwork-desktop-git`. Debian, Ubuntu and Fedora: `chatwithwork-desktop`. The `cww` command and the `cww-app` program keep their names. By @crmne ([#24](https://github.com/crmne/chatwithwork-desktop/pull/24)).
- **Windows installs to `%LOCALAPPDATA%\Programs\Chat with Work Desktop`**, and its background agent's logon task, Startup shortcut and start at login are named Chat with Work Desktop too. The macOS app's identifier is `com.chatwithwork.desktop`. By @crmne ([#24](https://github.com/crmne/chatwithwork-desktop/pull/24)).

## Fixed

- **Coming back from signing in in your browser no longer risks a "connection reset" page** instead of "You can close this tab". By @crmne ([#24](https://github.com/crmne/chatwithwork-desktop/pull/24)).

## Known limitations

- **This version needs Chat with Work's matching server, and 0.4 doesn't work with it.** The app and server now speak a protocol renamed with the app. chatwithwork.com updates with this release; update every computer you've paired. Your pairing carries over, so nothing needs pairing again.
- **Nothing carries over from 0.4's names.** Sign in to the Chat with Work window again. On Linux, remove `chatwithwork-local-agent` (or `-bin`, `-git`) before installing the new package; on Arch, pacman offers to. On macOS the app asks again for notifications and the microphone, and "Start at login" needs turning on again in Settings. On Windows the installer replaces 0.4; turn "Start at login" on again if you used it. Your pairing, shared folders and the agent's settings are kept everywhere.
- **Scanning needs a few things on Linux and macOS.** On Linux, SANE and Tesseract with your language (the packages recommend them, and the scan window names the command for a missing language). On macOS, SANE from Homebrew (`brew install sane-backends`). Windows needs only the scanner's TWAIN driver. macOS's own Image Capture and Windows' WIA scanners aren't supported yet.
- **Windows builds and the macOS `.pkg` remain unsigned.** The macOS `.dmg` is signed and notarized. Windows may show a SmartScreen warning.
- **On macOS and Windows, a connection lost while a page is open shows the web view's own error** until you reopen the window; only Linux switches to the offline page then.
- **On Windows on Arm, `cww tui` dictates only in the cloud.**
- **Linux needs WebKitGTK 4.1 and glibc 2.39 or newer** for the desktop package; the terminal-only `cww` archives still work elsewhere.
- **The app does not update itself.** Upgrade through your package manager or download this release. After upgrading a Linux package, run `systemctl --user restart cww.service`.
