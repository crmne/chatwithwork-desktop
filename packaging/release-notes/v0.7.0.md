Chat with Work Desktop now updates itself: from this version on, the Mac app and the Windows app download each new release in the background, check its signature, and install it when you restart. Commands run on Windows too, in a container Windows enforces, and Chat with Work can search code and change several files at once in folders you share. Dictation in the terminal gets its Whisper model by itself, and the scan window adds the language you read with one click.

Already installed? Upgrade once more through the package manager you used (`brew upgrade`, `winget upgrade`, `apt`, `dnf`, `pacman`) or download this release: 0.6 can't update itself. From 0.7.0 on, the Mac app from the `.dmg` and the Windows app update themselves; package managers keep updating the copies they installed. GitHub shows each file's SHA-256 beside it, and the signed `checksums.txt` lists all but the Linux packages; [PACKAGING.md](https://github.com/crmne/chatwithwork-desktop/blob/main/PACKAGING.md#release-assets) says what each one is for.

## New

- **The app updates itself.** Once a day it reads the latest release on GitHub, downloads it in the background, and refuses it unless `checksums.txt` carries a valid signature from the key built into the app and the download matches it. **Restart to Update** in the tray or in General installs it and brings your windows back, restarts the background agent on the new version, and puts the old version back if the new one doesn't start. General shows what it's doing, has **Check Now**, and a switch to stop checking. Copies installed with Homebrew, the AUR, `.deb` or `.rpm` packages, Nix or the Mac's `.pkg` aren't replaced: General says how to update them. Built on fastframe-update. By @crmne ([#91](https://github.com/crmne/chatwithwork-desktop/pull/91)).
- **Commands run on Windows.** Each run gets a container Windows enforces (Windows 11 24H2 with the August 2026 update or later), with the same approvals, limits and network switch as on Linux and macOS. By @crmne ([#80](https://github.com/crmne/chatwithwork-desktop/pull/80)).
- **Search code and change several files at once.** Chat with Work can search a shared folder's files by content or name, copy files, and change several files at once, each change approved as before, like a coding agent working in your folder. By @crmne ([#86](https://github.com/crmne/chatwithwork-desktop/pull/86)).
- **Whisper installs itself for dictation in the terminal.** Choosing On this computer downloads the Whisper model that suits the computer (Tiny, Base or Small, by its memory and cores), and the first dictation in `cww tui` downloads it while you speak, showing its progress. Nothing to download by hand; the model is still checked before use. By @crmne ([#88](https://github.com/crmne/chatwithwork-desktop/pull/88)).
- **Add a language in the scan window.** On Linux, **Add a language…** at the end of the language list downloads Tesseract's model for the language you pick, checks it, and picks it, with no package to install. On Windows it opens Windows' language settings. By @crmne ([#89](https://github.com/crmne/chatwithwork-desktop/pull/89)).

## Fixed

- **Notifications open their chat in the app after a login.** A background agent started before the desktop session had no display, so clicking a notification crashed the app on Linux and the chat opened in the browser instead. The agent now passes the desktop's display to the app, and the app started without one says why and exits. By @crmne ([#87](https://github.com/crmne/chatwithwork-desktop/pull/87)).

## Known limitations

- **0.6 doesn't update itself.** Move to 0.7.0 by hand or through your package manager once; later releases arrive by themselves on Mac and Windows.
- **On Linux the app doesn't update itself.** Update through your package manager, or run the one-line installer again.
- **SmartScreen may still warn about a downloaded Windows installer** while its signature builds a reputation; the updater and `winget` don't trigger it.
