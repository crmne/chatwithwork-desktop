Computer settings are simpler, browser access can cover all sites except the ones you block, and you can choose whether browser actions ask each time. General comes first, folder exclusions share one card, and site names are saved exactly as typed.

## New

- **Choose which sites the browser may use.** Pick **Only these sites** or **All sites except…**, with blocked sites taking priority in either mode. Existing installations keep their previous allowed sites; broader access needs your choice on this computer. By @crmne.
- **Choose when browser actions ask.** **Ask before browser actions** starts on. Turn it off locally to let your chats and local agents act on permitted sites without repeated prompts, including actions that send or delete information. Stop, blocked sites, protected fields and the separate settings for each bot still apply. Files and commands keep their existing approval rules. By @crmne.

## Fixed

- **Site names keep their final characters.** Saving a valid domain no longer stores an earlier draft of it. By @crmne.
- **Settings have fewer controls and less repetition.** General comes first. Browser has one switch for using it. Run commands stays visible when a prerequisite is missing. Custom exclusions and built-in protections share a single card, and unused bot-sharing rows are hidden. By @crmne.
- **Computer tabs stay visible while switching.** The accompanying Chat with Work server update keeps the native panel in place between tabs, including Back and Forward, while rechecking the device and account. By @crmne.
- **Update checks always run.** General shows Updates before Background agent. Checking runs at startup and daily; installation still waits for restart, and package-manager copies remain managed by their package manager. By @crmne.

## Known limitations

- **Animations can remain at 60 fps on Linux high-refresh displays.** This comes from the system WebKitGTK/GTK 3 rendering clock, even with GPU rendering enabled. The settings navigation fix does not remove that [upstream limitation](https://bugs.webkit.org/show_bug.cgi?id=199376#c8).
- **The tab-navigation fix and chat approval setting need a current Chat with Work server.** Update a self-hosted server too. Older servers retain their existing approval behavior.
- **The extension is still installed manually.** Replace its files and press **Reload** on its extension card. Desktop does not update unpacked extensions. An older extension pauses browser access when a newer site policy is selected, until the extension is updated.
- **Linux installations update through their package manager or the one-line installer.** Mac `.pkg` copies also remain package-managed; use the signed and notarized `.dmg` for the Mac app. The `.pkg` remains unsigned.
- **Windows SmartScreen may warn while the installer’s signature builds a reputation.**
- **Mac commands have CPU and elapsed-time limits, but no memory or process-count limit.**
